# Memory Book · Deutsch

German–English vocabulary flashcards, built as an installable web app (works offline).

- About 300 A1–A2 words, plus your own words
- Search in German or English, filter by word type (noun, verb, separable verb, adjective, adverb, preposition, pronoun, conjunction, phrase)
- Add words with a word-type label; duplicates are flagged before saving
- Audio for every word; words are saved on your device

Install on Android: open the link in Chrome → menu ⋮ → **Install app**. On iPhone: Safari → Share → **Add to Home Screen**.
